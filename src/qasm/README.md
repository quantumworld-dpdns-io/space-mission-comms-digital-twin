# OpenQASM Circuit Library

OpenQASM 3.0 circuit library for space-mission-comms-digital-twin.

## Circuits

- `bb84.qasm` — BB84 QKD preparation circuit
- `teleport.qasm` — Quantum teleportation
- `qecc_surface.qasm` — Surface code stabilizer measurements
- `qaoa_maxcut.qasm` — QAOA for MaxCut
- `grover_3.qasm` — Grover's search (3 qubits)
- `error_correction_repetition.qasm` — Repetition code
- `qkd_decoy.qasm` — Decoy-state QKD circuit
